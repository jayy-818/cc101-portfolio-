## Sample Pseudocode: Decimal to Binary
 
```
START
DISPLAY "Enter a whole number (0 or greater): "
INPUT n

IF n = 0 THEN
SET binary = "0"
ELSE
SET binary = ""
WHILE n > 0 DO
SET remainder = n MOD 2
SET binary = remainder + binary
SET n = n DIV 2
ENDWHILE
ENDIF

DISPLAY "Binary: ", binary
END
```
